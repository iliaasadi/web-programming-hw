توضیح درباره‌ی تاریخ کامیت‌ها: ددلاین تمرین ۱ تاریخ ۱۸ اکتبر بود و پاسخ‌های این تمرین قبل از آن آماده شده بودند. بعدتر برای مرتب کردن ریپو، فایل‌ها را داخل پوشه‌های hw1 و hw2 گذاشتم و چون گیت جابه‌جا کردن فایل‌ها را هم به‌صورت کامیت جدید ثبت می‌کند، تاریخ بعضی کامیت‌ها بعد از ددلاین ثبت شده است. در این کامیت‌ها فقط محل فایل‌ها عوض شده و محتوای پاسخ‌های تمرین ۱ تغییری نکرده است.
